# 春秋列国形势图

[![中文](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-red.svg)](README.md) [![English](https://img.shields.io/badge/lang-English-blue.svg)](README.en.md)

春秋时期（前770—前476）的交互历史地图：45 个时间节点的列国疆域，60 个诸侯国（周、晋、楚、齐、秦、鲁、宋、卫、郑、陈、蔡、曹、许、燕、吴、越，以及虢、虞、邢、纪、莒、邾、群舒、徐等小国）与 7 支戎狄部族（赤狄、白狄、山戎、西戎、伊洛之戎、大荔、淮夷），200 多处国都、城邑、关隘的古今地名对照，以及战役、会盟与文化事件、方城与齐长城、运河、山川、周边诸族。界面中英双语，地图右上角「中 | EN」切换。

本图与[战国列国形势图](https://jackyijun.github.io/zhanguo-map/)首尾相接：两图共用同一份归属点和同一张通行代价栅格，春秋末节点（前476）与战国首节点（前475）的疆域、配色逐像素一致。

## 三、本地构建

改了史料内容（`content/`）或参数（`src/config.py`）之后才需要重新构建。需要 **Python 3.9 或更新版本**。

**macOS / Linux**

```bash
cd chunqiu-map
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py --open
```

**Windows（PowerShell）**

```powershell
cd chunqiu-map
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --open
```

完整构建约 1 分钟，完成后会用浏览器打开新生成的 `docs/index.html`。

| 命令 | 作用 |
|---|---|
| `python run.py` | 底图缺失则下载 → 计算疆域 → 拼装 HTML |
| `python run.py --html` | 只重新拼装 HTML（只改了 `src/template.html`、`content/features.py` 里的文字或 `content/en/` 的英文时用，不到 1 秒） |
| `python run.py --draft` | 英文有缺译或过期时也照样出图（缺译处临时显示中文），只供预览；不加时构建会停下并列出缺译 |
| `python run.py --open` | 构建完后在浏览器中打开 |
| `python run.py --preview -632,-546` | 额外画出这几个节点的疆域草图到 `build/preview.png`，便于检查归属是否填错 |
| `python tools/preview.py -632 110,119,32,38` | 只画草图，可指定经纬范围（西,东,南,北） |

项目里已经带了底图数据（`geodata/ne/`，约 23 MB），离线也能构建。如果删掉了，`run.py` 会自动从 GitHub 下载固定版本（Natural Earth v5.1.2）。

同一份输入，构建结果逐字节一致，可以用 git 追踪改动。

构建完成后，把 docs/index.html 一起提交并推送到 main，线上网页会自动更新。

## 五、工作原理

```
content/seeds.txt ──┐
content/features.py ┼─► build.py ─► build/geo.json ─► assemble.py ─► docs/index.html
geodata/ (底图) ────┘                                    ▲
                          content/features.py + content/en/ + src/template.html
```

### 1. 为什么疆域要“算”出来

春秋没有现成的边界数据，史书能确定的大多是“某年某邑属某国”“某国灭某国”。所以这里只手写**地点 → 国家**的归属及其变化年份（`seeds.txt`），再用一张“通行代价”地图让计算机推出国与国之间的分界，让分界尽量落在山脊和大河上。

### 2. `build.py` 的步骤

1. **陆地**：从 Natural Earth 裁出东亚陆地，简化后编码。
2. **代价栅格**：0.05° 一格。陆地代价 1，海 4.5；每条山脉按“阻隔权重”加代价，古黄河、济水、易水、北洛水和江、汉、漳也加代价；再叠一层固定随机种子的平滑噪声。这张栅格与战国图完全相同，`config.py` 的 `COST_SHA` 每次核对。
3. **多源最短路**：从当年参与分区的归属点同时出发做 Dijkstra，每一格归给“走过去最近”的那个点。点集相同的节点只算一次。
4. **逐节点着色**：按 `seeds.txt` 查出每个点当年属哪国，把格子合并成各国范围，高斯平滑后描出轮廓并简化。注记位置取每国最大一块陆地的内部最远点。
5. **水系与湖泽**：Natural Earth 河流按英文名对到古名；黄河故道、济水、北洛水、伊洛、汝颍、泗水等手绘补上。
6. **地点归属**：每个城邑、关隘、战役点查它落在哪个归属点的格子里，带上那个点的归属变化，供提示框显示“某年属某国”。

### 3. `seeds.txt` 语法

每行一个点：

```
名称 经度 纬度 初始归属 [年份归属 ...] [~年份]
```

- `·` 表示不属任何诸侯国（戎狄蛮夷之地，或空白）；部族也有自己的键（如 `赤狄`、`白狄`）。
- 年份用负数表示公元前，`-655晋` 表示前655 年起属晋。
- `~-350` 表示这个点从前350 起不再参与分区：为春秋小国、戎狄和战国早期补的点都带这个标记，前350 以后只用原战国图的点，战国图前350 以后的疆域因而与补点之前完全相同。

例：

```
陕 111.2 34.76 虢 -655晋 -453魏 -324秦
潞 113.2 36.1 赤狄 -594晋 -453韩 -262赵 -260秦 -257赵 -247秦
下阳 111.3 34.83 虢 -658晋 -453魏 ~-350
许叶 113.52 33.58 申 -688楚 -576许 -533楚 -529许 -524楚 -506许 -390楚 ~-350
```

### 4. 与战国图的衔接

- 两个仓库的 `content/seeds.txt` 完全相同，山脉、手绘界河的几何与阻隔权重也相同（`COST_SHA` 校验）。
- 任何一行都不在前475 这一年变更归属，所以春秋图前476 与战国图前475 用的是同一组点、同一张栅格、同一份归属，算出的疆域多边形和国名位置逐字节一致。
- 两图共有的国家（秦、楚、齐、晋、郑、吴、越等 28 个）同键同色，`features.py` 的 `STATE_COLORS` 里浅、深两值完全相同。
- 改其中一张图的 `seeds.txt` 或山脉、界河时，另一张图要同步修改并一起重建。

### 5. `features.py` 里有什么

| 名称 | 内容 |
|---|---|
| `STATES` · `STATE_COLORS` | 67 个政权与部族的姓氏、介绍，以及浅色 / 深色两套疆域色 |
| `STATE_KIND` · `STATE_ALIAS` | 戎狄部族（淡色虚线、不计入国数）；当年别名（前506 以前中山注记为“鲜虞”，前638 起伊洛之戎注记为“陆浑之戎”） |
| `SNAPS` · `SNAP_SHORT` | 45 个时间节点：年份、标题、一段概述；时间轴上竖排的短名 |
| `FIRST` · `PERIOD0` · `PLAY_MS` | 首屏节点（前632）、第一个节点“本期”的起算年、播放间隔 |
| `CAPITALS` | 91 处国都，含起止年份（迁都后旧都显示为虚线框） |
| `BATTLES` | 64 场战役：年份、胜负、主将、经过 |
| `PASSES` · `CITIES` · `TOWNS` | 关隘津渡、名城要邑、一般城邑 |
| `CULTURE` | 48 处事件、会盟、人物与考古遗址 |
| `WALLS` · `RANGES` | 楚方城、齐长城；24 条山脉 |
| `NE_RIVERS` · `MANUAL_RIVERS` · `CANALS` · `MARSHES` · `NE_LAKES` · `LAKE_NOTES` · `RIV_OVERRIDE` | 水系古名、手绘河道、运河（邗沟、菏水，按开凿年份出现）、古泽薮、湖泊 |
| `PEOPLES` | 20 处周边诸族注记，按存续年份显示 |
| `FALLS` | 年表里的灭国条目：年份、亡国名、经过 |

### 6. 前端显示规则

- 战役只显示**本期**的，即上一个节点之后（不含）到本节点（含）发生的；说明栏末尾列出“本期战役”，点击即定位。
- 事件、长城、运河只显示到当前节点为止已经发生的；国都只显示当时的国都和已废的旧都。
- 戎狄部族的疆域淡色、虚线边，注记斜体，不计入顶栏的国数。
- 图例只列本期尚存的政权和本期新亡的政权（划掉），部族排在最后。
- 缩放分级：全图只显示国名、国都、战役；放大后才出现关隘、名城、一般城邑和今名。

## 六、常见修改

| 想做的事 | 改哪里 | 之后运行 |
|---|---|---|
| 改某邑某年的归属 | `content/seeds.txt` 对应一行（语法见上节）；**战国图仓库同步改** | 两图都 `python run.py` |
| 加一个城邑、关隘、战役、事件 | `content/features.py` 对应列表加一行 | `python run.py --html` |
| 加一个时间节点 | `SNAPS` 加一行（年份、标题、概述），`SNAP_SHORT` 加短名 | `python run.py` |
| 改说明文字 | `features.py` 里的按语、节点概述 | `python run.py --html`（会提示对应英文过期，见下节） |
| 改英文 | `content/en/*.json` | `python tools/i18n.py lock` → `python run.py --html` |
| 改配色 | `STATE_COLORS`；两图共有的国家须在战国图里同步改 | `python run.py --html` |
| 改界面文字 | `src/template.html` 里的 `U`（`zh`、`en` 两套） | `python run.py --html` |

## 七、英文版

同一个 `docs/index.html` 里有中、英两种界面，默认中文；地图右上角「中 | EN」切换，选择记在浏览器里，网址加 `#en` 直接打开英文。英文模式下地图只标英文，悬停说明、索引、年表、对照表在英文名后附小号汉字原名；检索同时收中英文，英文不分大小写。

- **中文是源文本。** 英文按“文件 · 键 · 字段”另存在 `content/en/`：条目键为 `类别:古名`（同类同名的第二条起加 `#2`），节点键为年份，今省名为 `prov:省名`，灭国条目为 `fall:年份`，当年别名为 `alias:键:别名`。
- **指纹。** `zh.lock.json` 记下每条英文所据中文的 sha1 前 10 位。中文一改，对应英文就算“过期”；`assemble.py` 默认严格，有缺译或过期就停下，`--draft` 才放行。
- **工具。** `python tools/i18n.py status` 看缺译、过期条数；`todo` 导出待译中文；`table` 导出中英对照表 `build/i18n_table.csv`；`lock` 登记指纹。
- **译名体例**见 `content/en/GLOSSARY.md`，与战国图体例一致，两图同名同译。

## 八、调参

所有可调参数都在 `src/config.py`。**栅格、代价、噪声相关的参数两图必须一致**，改动后 `COST_SHA` 会报错，须两图一起改并更新校验值。

| 参数 | 作用 |
|---|---|
| `RES` | 栅格边长 |
| `SEA_COST` | 跨海代价 |
| `NOISE_SEED` · `NOISE_AMP` | 界线弯曲的随机种子与幅度 |
| `RANGE_WIDTH` · `RIVER_COST` | 山脊阻隔带宽度、界河代价 |
| `SMOOTH_SIGMA` · `POLY_SIMPLIFY` | 轮廓平滑程度与简化容差（只影响描边，两图可各自调，但衔接节点会因此不再逐字节相同） |

## 九、资料与可靠程度

- **疆域归属**：依据《左传》《史记》《国语》《竹书纪年》等史料与谭其骧《中国历史地图集》第一册春秋图的大意推定，由 AI 协助编写，未逐条核对原文。大的格局和关键年份（如前655 晋灭虢虞、前632 城濮、前597 邲、前567 齐灭莱、前506 吴入郢、前487 宋灭曹、前478 楚灭陈）比较可靠；早期诸国的范围、边缘地区（戎狄、群舒、江南、巴蜀）较粗略。
- **边界线**：完全是推算的示意线，只表示“这一带属于这个国家”。
- **小国与戎狄**：春秋诸侯百余，图上只画出六十个；不单独画出的小国（如温、原、应、蒋、宿、颛臾）并入邻近大国。戎狄的分布多据《左传》零星记载示意。
- **有争议处**：地图里注明“一说”“地望有争议”，如楚都丹阳、故绛、邾早期都城、杞的东迁路线；楚早期疆域兼取丹淅、荆睢两说。随（曾）、许的灭亡年代史无明文，图上分别示意为约前360、约前390。
- **英文**：译名与按语由 AI 翻译，经独立复核；体例见 `content/en/GLOSSARY.md`。英文与中文不一致时以中文为准。
- **底图**：Natural Earth 1:10m（公有领域）；今省界沿用自作者此前的另一张地图。

有错欢迎指正。
